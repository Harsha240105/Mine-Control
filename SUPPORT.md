### Before Opening an Issue

1. **Search existing issues** — Your question may already be answered
2. **Check the FAQ** in [README.md](README.md#faq) for common questions
3. **Try the Troubleshooting guide** in [README.md](README.md#troubleshooting)
4. **Update to the latest version** — Your bug may already be fixed

### Reporting a Bug

Open a [Bug Report](https://github.com/Harsha240105/Mine-Control/issues/new?template=bug_report.md) and include:

- MineControl OS version (find in Settings → About or Help → About)
- Your operating system (Windows 10/11, macOS, Linux)
- Minecraft version and server software (Paper, Fabric, etc.)
- Java version (`java -version` output)
- Steps to reproduce
- Screenshots or console logs
- Any error messages (from the app or server console)

### Requesting a Feature

Open a [Feature Request](https://github.com/Harsha240105/Mine-Control/issues/new?template=feature_request.md) and include:

- What problem you're trying to solve
- How you envision the feature working
- Any alternatives you've considered

### Security Issues

For security vulnerabilities, **do not** open a public issue. Instead:

1. Open a GitHub Issue with the label `security` (visible only to maintainers)
2. Or email the maintainer directly (see commit history for contact)

See [SECURITY.md](SECURITY.md) for the full security policy.

### For Maintainers

- All support requests are tracked via GitHub Issues
- Response target: initial acknowledgment within 24 hours
- Resolution target: 7 days for bugs, 30 days for feature requests
